\## 📋 О проекте



Радиус экзопланеты — ключевая характеристика, определяющая её природу: каменистая ли это планета земного типа, газовый гигант или «нептун». Прямое измерение радиуса возможно только \*\*транзитным методом\*\* (по падению блеска звезды при прохождении планеты по её диску). Для планет, обнаруженных методом радиальных скоростей или микролинзирования, радиус часто неизвестен или оценивается крайне грубо — через модельные соотношения «масса–радиус».



\*\*Цель проекта:\*\* построить модель линейной регрессии, которая предсказывает радиус экзопланеты (в радиусах Земли) по доступным характеристикам — массе, орбитальным параметрам, параметрам звезды.



\*\*Данные:\*\* \[NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/) — таблица подтверждённых экзопланет (40350 записей, 92 колонки).



\*\*Стек:\*\* Python, pandas, numpy, scikit-learn, matplotlib, seaborn, joblib.

\*\*Финальная модель (тест, 951 строка):\*\*

\- \*\*MAE = 1.52 R⊕\*\* — в 1.7 раза точнее исходной.

\- \*\*R² = 0.76\*\* — модель объясняет 76% вариативности радиуса.

\- \*\*MAPE = 52%\*\* — вдвое точнее исходной по относительной ошибке.

\- \*\*RMSE = 2.36 R⊕\*\* — приемлемая «неравномерность» ошибок.



\### Модель адаптивна



Финальная модель работает в \*\*двух режимах\*\*:



| Сценарий | Пример | Ошибка | Комментарий |

|---|---|---|---|

| \*\*Масса известна\*\* (RV-наблюдения) | Планета 5.49 R⊕ → предсказано 5.72 R⊕ | \*\*0.23 R⊕ (4%)\*\* | Почти идеально |

| \*\*Масса неизвестна\*\* (`None`) | Та же планета → предсказано 2.46 R⊕ | 3.03 R⊕ | Консервативная оценка — модель «знает», что данных недостаточно |



Это \*\*честнее\*\*, чем притворяться, что модель работает с одинаковой точностью для всех планет.

\## 💡 Топ-5 инсайтов



\### 1. «Пустыня Нептуна» в распределении радиуса

Распределение `pl\_rade` в лог-шкале \*\*бимодальное\*\*: два горба (суперземли \~2 R⊕ и газовые гиганты \~12 R⊕) с провалом между ними на 4–8 R⊕. Это известный в астрофизике феномен — \*\*«пустыня Нептуна»\*\* (Neptunian desert): планет в этой зоне мало из-за фотоиспарения атмосфер близкими к звезде планетами.



\### 2. Масса планеты — главный физический предиктор

`pl\_bmasse` ↔ `pl\_rade`: \*\*r = 0.86\*\* в лог-шкале. Это фундаментальное соотношение «масса–радиус». Без массы R² падает с 0.46 до 0.27 — это подтверждает её ключевую роль.



\### 3. 68% пропусков массы «размывают» сигнал

Для транзитных планет масса часто неизвестна (RV требует дополнительных наблюдений). Заполнение медианой «замораживает» признак — модель не может отличить газовый гигант от суперземли. Это \*\*фундаментальное ограничение данных\*\*, а не модели.



\### 4. `is\_missing\_mass` — ключевое инженерное улучшение (R² = 0.46 → 0.76)

Добавление \*\*бинарного флага пропуска массы\*\* дало качественный скачок: \*\*R² вырос на 63%\*\*, MAE упал на 42%, MAPE — вдвое. Модель теперь «знает», где масса ненадёжна, и корректирует предсказание. Это классический приём \*\*missing indicator\*\* в ML.



\### 5. Модель «вылечила» регрессию к среднему

Residual plot показал: до флага модель систематически \*\*переоценивала\*\* мелкие планеты и \*\*недооценивала\*\* крупные. После флага ошибки сократились во всех группах:



| Группа радиусов | Без флага | С флагом | Улучшение |

|---|---|---|---|

| < 2 R⊕ (суперземли) | −1.68 | \*\*−0.76\*\* | +0.92 |

| 2–4 R⊕ (нептуны) | −0.59 | \*\*−0.12\*\* | +0.47 |

| 8–15 R⊕ (юпитеры) | +3.69 | \*\*+0.69\*\* | \*\*+3.00\*\* |

| > 15 R⊕ (гиганты) | +7.90 | \*\*+5.15\*\* | +2.74 |



Наибольшее улучшение — там, где было хуже всего.

import joblib
import numpy as np
import pandas as pd

# Загрузка артефактов (один раз при старте сервиса)
model = joblib.load('artifacts/model_flag.joblib')
params = joblib.load('artifacts/preprocessing_params.joblib')

def predict_planet_radius(pl_bmasse=None, st_rad=None, st_teff=None, ...):
    """
    Предсказывает радиус экзопланеты в R⊕.
    Если pl_bmasse = None — модель «знает», что масса ненадёжна,
    и даёт консервативную оценку.
    """
    # Лог-трансформация
    log_cols = ['pl_bmasse', 'pl_orbsmax', 'st_rad', 'st_mass', 'sy_dist', 'sy_pnum']
    raw = {col: (np.log10(v) if v and v > 0 else np.nan) for col, v in {...}.items()}
    
    # Заполнение медианами и стандартизация
    features = pd.DataFrame([raw]).fillna(params['medians'])
    features['is_missing_mass'] = 1 if pl_bmasse is None else 0
    features = features[params['columns']]
    features_scaled = (features - params['train_mean']) / params['train_std']
    
    return model.predict(features_scaled)[0]

# Пример: планета-нептун с известной массой
radius = predict_planet_radius(pl_bmasse=17.3, st_rad=1.108, ...)
print(f'Предсказанный радиус: {radius:.2f} R⊕')

⚠️ Ограничения и предупреждения
1. R² = 0.76 ниже целевого (≥ 0.85)
Связано с линейной архитектурой: LinearRegression не может уловить нелинейные связи масса–радиус (для газовых гигантов соотношение не степенное, а «насыщается»). Для достижения R² ≥ 0.85 нужны нелинейные модели (RandomForest, GradientBoosting).

Для production-применения в задачах грубой оценки (MAE = 1.52 R⊕ — это ~60% от медианного радиуса) модель достаточна. Для научных публикаций — нет.

2. is_missing_mass кодирует селекцию миссии Kepler
Флаг отражает наблюдательную селекцию: мелкие планеты часто не имеют RV-масс, потому что RV требует больше времени. При переходе на TESS или PLATO флаг потребует переобучения — иначе модель будет «ожидать» старую селекцию и давать смещённые предсказания.

3. Модель обучена только на транзитных планетах
Для планет, найденных другими методами (RV, микролинзирование, визуализация), модель не применима без переобучения — там радиус либо неизвестен, либо измерен грубо.

4. Мультиколлинеарность st_rad ↔ st_mass (r = 0.899)
Коэффициент st_mass в модели может быть отрицательным (артефакт мультиколлинеарности). Lasso с alpha = 0.05 зануляет st_mass и st_teff как избыточные — это подтверждает интерпретацию.

🔮 Перспективы развития
- Нелинейные модели (RandomForest, GradientBoosting, XGBoost): ожидаемое улучшение R² до 0.80–0.85.

- Индикаторы других пропусков (is_missing_eccen, is_missing_orbsmax): по аналогии с is_missing_mass. Могут дать дополнительный прирост.

- Отдельные модели по массовым режимам: суперземли (1–4 R⊕) vs газовые гиганты (8–20 R⊕).

- Интеграция с RV-каталогами (HARPS, ESPRESSO): увеличение доли планет с известной массой — главный bottleneck.

- Развёртывание в API (Flask / FastAPI): артефакты готовы к использованию.

- SHAP-анализ для интерпретируемости предсказаний в конкретных случаях.
